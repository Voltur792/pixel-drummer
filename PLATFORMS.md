# Поддержка платформ

Linux и macOS — **экспериментальные**. Проверки Python и автоматические тесты не заменяют проверку графики, звука и работы внутри Astra на реальной ОС. Windows сохраняет прежние возможности.

Официальные хосты Astra сейчас доступны для Windows x64 и Linux x64. Код подготовлен также под macOS, но официального хоста Astra для Mac и ARM пока нет: установить и полноценно проверить плагин там внутри Astra нельзя. См. [платформы Astra](https://github.com/mihailinl/AstraPlugins/blob/master/docs/en/1-orientation/platforms.md).

Сцена, выбор инструментов, анимации и деморежимы подготовлены для Linux/macOS. Нужен Python 3.12 или новее и зависимости плагина. Нативные окна и звук вне Windows вручную не проверялись.

- Windows: прежний захват воспроизводимого звука, прогулки по окнам и игра с копиями значков сохранены.
- Linux: для реакции на музыку нужен PulseAudio либо совместимый сервер PulseAudio в PipeWire и библиотека `libpulse`. Для Qt нужны библиотеки вашей графической среды. Под X11 доступно перемещение собственной сцены; взаимодействие с чужими окнами и значками отключено.
- Wayland: X11 принудительно не включается; используется выбранный Qt backend. Автоматические прогулки между экранами отключены. Положение прозрачного окна и показ поверх остальных зависят от композитора.
- macOS: SoundCard не предоставляет встроенный loopback CoreAudio. Для реакции на музыку самостоятельно настройте виртуальный звуковой маршрут и задайте точное имя либо ID его входа в `PIXEL_DRUMMER_LOOPBACK_DEVICE`. Указывайте именно настроенный виртуальный вход для музыки. Без него физический микрофон автоматически не выбирается; доступны деморежимы `slow`, `mid`, `fast`. Перемещение по чужим окнам и игра со значками отключены.

Пакет персонажа находится в конфигурации Astra: Linux — `$XDG_CONFIG_HOME/astra/companion/pack` (по умолчанию `~/.config/astra/companion/pack`), macOS — `~/Library/Application Support/com.astra.astra/companion/pack`. Для нестандартной установки задайте `PIXEL_DRUMMER_PACK`; данные самого плагина можно перенести через `PIXEL_DRUMMER_DATA`. На Windows прежние каталоги сохранены.
